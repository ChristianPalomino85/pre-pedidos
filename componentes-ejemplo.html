Documentación y Uso

Archivos Principales:

  • css/main.css - Sistema de diseño centralizado con variables CSS
  • js/components.js - Componentes JavaScript interactivos

Cómo Usar:

  1. Incluye los archivos CSS y JS en tu HTML
  2. Usa las clases predefinidas para botones, cards, formularios, etc.
  3. Los componentes JS se inicializan automáticamente
  4. Personaliza usando variables CSS en :root

Variables CSS Principales:

--az-primary: #d46321; --az-primary-dark: #b34710; --font-size-base: 1rem; --space-2: 1rem; --radius-base: 0.5rem; --shadow-base: 0 4px 6px rgba(0,0,0,0.1);
Tip: Puedes sobrescribir cualquier variable CSS en tu propio archivo para personalizar el diseño.
